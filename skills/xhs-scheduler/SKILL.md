## 发布建议生成逻辑

### 第一步：分析内容属性

读取笔记 frontmatter：
- 内容类型（干货/种草/测评/vlog/...）
- 账号领域（数码/美妆/美食/...）
- 选题紧迫度（🔥趁热发 / 📅本周 / 📦备用）

### 第二步：匹配最佳时间

**按内容类型推荐：**

| 内容类型 | 最佳时段 | 最佳星期 | 理由 |
|---------|---------|---------|------|
| 数码测评 | 20:00-22:00 | 周四/周五 | 理性消费决策，晚间思考 |
| 美妆护肤 | 12:30-13:30 | 周六/周日 | 午休闲逛，周末购物欲强 |
| 美食探店 | 11:30-12:30 | 周五/周六 | 就餐前决策时机 |
| 旅行攻略 | 20:00-22:00 | 周四/周五 | 提前规划周末出行 |
| 职场干货 | 07:30-09:00 | 周一/周三 | 通勤学习心态 |
| 母婴育儿 | 09:00-11:00 | 周二-周四 | 宝妈在家时间 |
| 健身运动 | 07:00-08:00 | 周一/周三/周五 | 健身打卡时机 |

**紧迫度修正：**
- 🔥 趁热发：在热点爆发后 6-24 小时内发，选当天最近的黄金时段
- 📅 本周发：优先周四/周五晚间
- 📦 备用选题：无时间限制，选最佳时段即可

### 第三步：输出具体建议

```
📅 发布排期建议

📌 笔记：[标题]
📁 类型：[内容类型]
⏰ 建议发布时间：[具体日期（周X）] [具体时间]
📍 选择理由：[为什么这个时间合适]

💡 发布优化建议：
- [针对性的发布技巧1]
- [针对性的发布技巧2]

🔁 互动运营建议：
- 发布后前30分钟：主动回复前3-5条评论
- 发布后2小时内：不要修改正文（影响推荐）
- 互动引导：在评论区补充1条有价值的信息（自评）
```

## 发布 Checklist

每次发布前逐项检查：

```
发布前检查清单：

内容
□ 标题已选定（≤20字）
□ 正文已复制（≤1000字）
□ 话题标签已准备（3-8个）
□ 内容无违规词汇

图片
□ 封面图已准备（竖图3:4）
□ 内容图已准备（1-9张）
□ 图片文字清晰可读
□ 图片风格统一

发布设置
□ 发布时间已设置（或选择定时发布）
□ 位置标签（可选，提升本地流量）
□ 合集归档（如有）

发布后
□ 30分钟内：检查展示效果
□ 30分钟内：回复前3条评论
□ 2小时内：不修改正文
□ 次日：查看数据（播放/点赞/收藏/评论/涨粉）
```

## 数据追踪建议

发布后 24 小时查看：

| 指标 | 参考基准 | 说明 |
|------|---------|------|
| 曝光量 | 发布24h内 | 推送量级的参考 |
| 点击率 | ≥5% 为良好 | 封面和标题的吸引力 |
| 互动率 | ≥2% 为良好 | 点赞+收藏/曝光 |
| 收藏率 | ≥1% 为良好 | 干货内容的核心指标 |
| 评论数 | 任何评论都值得回复 | 互动质量 |

**数据差怎么办：**
- 曝光低 → 话题标签调整，考虑重发或修改封面
- 点击率低 → 封面/标题优化方向
- 互动率低 → 内容质量或 CTA 引导问题
- 收藏高但评论少 → 正常（干货笔记），无需担忧
