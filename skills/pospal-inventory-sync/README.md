# 银豹库存同步技能 (Pospal Inventory Sync Skill)

## 📋 技能概览

一个安全、可靠、高效的银豹POS系统库存自动化管理工具。通过环境变量管理凭据，避免敏感信息泄露，提供完整的库存管理功能。

## ✨ 特性

### 🔒 安全优先
- ✅ **环境变量管理** - 凭据通过环境变量存储，绝不硬编码
- ✅ **配置文件安全** - 配置文件只包含非敏感信息
- ✅ **操作审计** - 清晰的日志记录所有操作
- ✅ **错误隔离** - 单点故障不影响整体运行

### 🚀 简单易用
- ✅ **一键设置** - 交互式环境变量配置脚本
- ✅ **清晰提示** - 友好的错误信息和解决建议
- ✅ **完整示例** - 多种使用场景示例代码
- ✅ **详细文档** - 从安装到使用的完整指南

### ⚡ 高效可靠
- ✅ **批量操作** - 支持CSV和JSON格式批量处理
- ✅ **自动重试** - 网络波动自动重试机制
- ✅ **结果验证** - 操作后自动验证结果
- ✅ **超时控制** - 可配置的超时设置

### 🔧 可扩展
- ✅ **模块化设计** - 核心功能集中，易于扩展
- ✅ **统一接口** - 所有脚本使用相同的环境变量机制
- ✅ **完整API** - 提供Python类和命令行接口
- ✅ **易于集成** - 可集成到现有系统和工作流

## 🚀 快速开始

### 1. 安装依赖
```bash
cd scripts
pip install playwright
playwright install chromium
```

### 2. 设置环境变量
```bash
./setup_env.sh
# 或手动设置
export POSPAL_USERNAME="你的用户名"
export POSPAL_PASSWORD="你的密码"
```

### 3. 测试连接
```bash
python3 test_connection.py
```

### 4. 开始使用
```bash
# 查看库存
python3 check_inventory.py

# 修改库存
python3 update_single_product.py --product "鞋子" --stock 10

# 批量操作
python3 batch_update.py --json '{"鞋子": 5, "衣服": 20}'
```

### 环境要求
- **Python**: 3.7+
- **依赖**: playwright
- **浏览器**: Chromium
- **系统**: Linux/macOS/Windows
