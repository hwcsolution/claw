# 正文模板

## 6大模板

### 模板1：干货分享型
```markdown
开头：
姐妹们！[痛点描述]，真的太[情绪词]了！
今天分享[数字]个[方法]，亲测有效！

中间：
✨ [要点1]
[具体说明]

✨ [要点2]
[具体说明]

结尾：
觉得有用记得点赞收藏⭐
有问题评论区问我哦～
```

### 模板2：产品测评型
```markdown
开头：
[产品名]到底值不值得买？
用了一段时间，来说说真实感受！

中间：
📦 产品信息
品牌/价格/购买渠道

✅ 优点：...
❌ 缺点：...

结尾：
总的来说，[评价]
有问题评论区问我～
```

### 模板3：教程攻略型
```markdown
开头：
手把手教你[达成目标]！
零基础也能学会，建议收藏⭐

中间：
Step 1：[步骤]
💡 小技巧：[提示]

Step 2：[步骤]
...

结尾：
学会了吗？快去试试！
```

### 模板4：探店分享型
```markdown
开头：
终于打卡了[店名]！

中间：
📍 店铺信息
🏠 环境
🍽️ 菜品推荐

结尾：
总体推荐指数：⭐⭐⭐⭐⭐
```

### 模板5：好物分享型
```markdown
开头：
[数字]个[品类]宝藏好物分享！

中间：
1️⃣ [产品名]
💰 价格 / 🌟 推荐理由

2️⃣ [产品名]
...

结尾：
有问题评论区问我！
```

### 模板6：对比测评型
```markdown
开头：
[产品A] vs [产品B]，哪个更值得买？

中间：
📊 基础信息对比
✨ 使用感受对比
🏆 各自优势

结尾：
👉 选A如果你：[场景]
👉 选B如果你：[场景]
```

## 写作要点

- 分点叙述，每点2-4行
- 口语化，像朋友聊天
- 适当emoji增加可读性
- 真实体验感，有细节
- 字数控制在1000字内
