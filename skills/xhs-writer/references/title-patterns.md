# 爆款标题公式

## 8大公式

### 公式1：数字+结果+方法
```
模板：[数字]个[方法]，[结果]
示例：
- 3个动作，一周瘦5斤
- 5个习惯，皮肤变好10倍
- 7天早起，人生改变了
```

### 公式2：痛点+解决方案
```
模板：还在[痛点]？试试[解决方案]
示例：
- 还在为穿搭烦恼？试试这3个公式
- 还在熬夜刷手机？试试这个方法
```

### 公式3：身份认同+利益
```
模板：[身份]必看/必入的[利益]
示例：
- 打工人必看的省钱攻略
- 宝妈必入的辅食工具
```

### 公式4：对比反差
```
模板：[之前]vs[之后]
示例：
- 买房前vs买房后，差距太大
- 减肥前vs减肥后，判若两人
```

### 公式5：疑问+悬念
```
模板：为什么[现象]？原来[原因]
示例：
- 为什么别人穿搭好看？原来有公式
- 为什么皮肤越来越好？秘密在这
```

### 公式6：情绪+场景
```
模板：[情绪词]！[场景描述]
示例：
- 绝了！这个穿搭公式太好用了
- 破防了！原来这样省钱
```

### 公式7：清单盘点
```
模板：[数字]款[品类]推荐
示例：
- 10款平价粉底液测评
- 8个宝藏APP推荐
```

### 公式8：时间限定
```
模板：[时间]做[事情]，[结果]
示例：
- 坚持一个月早起，变化惊人
- 每天十分钟，练出马甲线
```

## 高频情绪词

**正面**：绝了、真香、爱了、必入、必囤、宝藏、神仙
**负面**：踩雷、避坑、智商税、血泪教训
**疑问**：为什么、怎么、如何、真的有用吗

## 标题禁忌

❌ 过度夸张
❌ 虚假承诺
❌ 标题党
❌ 超过20字
