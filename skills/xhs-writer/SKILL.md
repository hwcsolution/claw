# xhs-writer - 小红书笔记创作

从选题到成稿，输出符合小红书调性的爆款内容。

## 硬性限制

- **标题**：≤ 20 字
- **正文**：≤ 1000 字
- **风格**：口语化种草风，真实体验感

## 工作流程

### Step 1: 确认主题和需求

询问用户：
- 主题/话题
- 内容类型（干货/测评/分享/教程...）
- 目标人群
- 是否有素材/图片

### Step 2: 搜索参考爆款

```
搜索主题相关 Top 10 爆款
提取：标题规律、正文结构、高频标签
目的：借鉴规律，不是抄袭
```

### Step 3: 生成标题（5个选项）

**爆款公式**（见 references/title-patterns.md）：

1. 数字+结果+方法
2. 痛点+解决方案
3. 身份认同+利益
4. 对比反差
5. 疑问+悬念
6. 情绪+场景

**生成规则**：
- 字数 ≤ 20
- 包含情绪词/数字/疑问
- 避免标题党

### Step 4: 撰写正文

**结构模板**（见 references/content-templates.md）：

```
开头（钩子）：
- 痛点共鸣
- 场景代入
- 疑问引发

中间（干货）：
- 分点叙述
- 每点 2-4 行
- 具体可操作

结尾（互动）：
- 引导点赞收藏
- 邀请评论
```

**写作要点**：
- 口语化，像朋友聊天
- 真实体验感，有细节
- 适当 emoji 增加可读性
- 避免营销腔、AI味

### Step 5: 优化标签

**策略**：
- 数量：3-5 个
- 组合：1品类 + 2场景 + 1-2长尾
- 优先有搜索量的标签

### Step 6: 字数自检

```
标题字数：xx / 20 ✓/✗
正文字数：xx / 1000 ✓/✗
```

超限则精简。

### Step 7: 输出成稿

```markdown
## 📌 标题选项

1. [标题1] (xx字)
2. [标题2] (xx字)
3. [标题3] (xx字)
4. [标题4] (xx字)
5. [标题5] (xx字)

## 📝 正文 (xx字)

[正文内容]

## 🏷️ 标签

#[标签1] #[标签2] #[标签3] #[标签4]

---

✅ 字数检查通过
```

## 使用示例

### 方式一：给主题，完整创作
```
用户：写一篇小红书，主题是"上班族快速晚餐"

执行：
1. 搜索"快速晚餐"爆款参考
2. 生成5个标题选项
3. 撰写正文
4. 优化标签
5. 字数自检
6. 输出成稿
```

### 方式二：用户提供素材
```
用户：我有几张便当照片，帮我写一篇"打工人一周便当"

执行：
1. 结合图片构思内容
2. 生成标题+正文+标签
3. 输出成稿+配图建议
```

### 方式三：仅生成文案
```
用户：帮我写个小红书文案，主题是"新手化妆避坑"，不用配图

执行：
1. 创作标题+正文+标签
2. 不生成配图建议
```

## 注意事项

- 必须真实，不写虚假体验
- 必须原创，不抄袭搬运
- 必须口语化，去AI味
- 字数超限必须精简
