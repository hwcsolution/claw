# 广告内容一站式合规审核技能

## 概述

本技能提供广告内容的一站式合规审核服务，支持：
1. 图片OCR文字提取（使用Qwen2.5-VL-72B模型）
2. 广告法违禁词检测
3. 平台规则合规审核
4. 生成统一合规报告

## 功能特点

- **多格式输入**: 支持纯文本、单张/多张图片、图文混合
- **高精度OCR**: 使用Qwen2.5-VL-72B模型提取图片文字
- **双重审核**: 广告法审核 + 平台规则审核
- **智能修改**: 自动生成合规版文案
- **详细报告**: 结构化Markdown报告，清晰易读
- **多平台适配**: 支持小红书、抖音、微信、微博等平台

## 使用方法

### 方法1：命令行使用
```bash
# 审核纯文本
python advertising_audit.py "我们的产品是市场上最好的，100%有效"

# 审核文本+图片
python advertising_audit.py "广告文案内容" image1.png image2.jpg

# 审核多张图片
python advertising_audit.py "" poster1.png poster2.jpg banner.png
```

### 方法2：在OpenClaw中调用
当用户发送包含以下关键词的消息时，自动触发技能：
- 广告审核
- 合规检查
- 违禁词检测
- 公关稿审核
- 海报检查
- 广告图合规

### 方法3：Python API调用
```python
from advertising_audit import AdvertisingContentAudit

# 初始化审核器
auditor = AdvertisingContentAudit(api_key="your_api_key")

# 审核内容
report = auditor.process(
    user_text="广告文案内容",
    image_paths=["ad1.png", "ad2.jpg"]  # 可选
)

print(report)
```

## 输入输出说明

### 输入格式
- **文本**: 任意广告文案、宣传语、产品描述
- **图片**: PNG、JPEG、WEBP格式，支持多张
- **图文混合**: 文本 + 一张或多张图片

### 输出格式
生成结构化Markdown报告，包含：
1. **审核概览**: 时间、类型、风险等级、评分
2. **广告法审核结果**: 违禁词、位置、法律依据、修改建议
3. **平台规则审核结果**: 违规项、平台适配性
4. **修改建议**: 自动修改版文案、关键修改点
5. **审核结论**: 通过/警告/违规建议

## 审核标准

### 广告法违禁词
- **高风险**: 最、第一、顶级、唯一、国家级、完美、绝对、100%、百分之百
- **中风险**: 首选、最佳、极品、绝佳、顶尖、超强、极致、无敌
- **低风险**: 优质、高效、专业、领先、先进、卓越、出色

### 平台敏感词
- **小红书**: 微信、QQ、加我、私信、低价、优惠、折扣
- **抖音**: 微信、加好友、转账、付款、低价、特价
- **微信**: 诱导分享、集赞、转发、关注、抽奖
- **微博**: 政治敏感、谣言、虚假信息、侵权

## 错误处理

- **网络错误**: 自动重试，显示友好错误信息
- **图片读取失败**: 跳过该图片，继续处理其他内容
- **API调用失败**: 降级到本地审核模式
- **内存不足**: 分批处理大图片

## 性能优化

1. **图片压缩**: 大图片自动压缩后再OCR
2. **批量处理**: 多张图片并行处理
3. **缓存机制**: 相同图片内容缓存OCR结果
4. **增量审核**: 只审核修改部分

## 注意事项

1. **API费用**: OCR调用会产生API费用，注意使用量控制
2. **处理时间**: 图片OCR可能需要几秒到几十秒
3. **准确率**: OCR准确率约95%，重要内容建议人工核对
4. **法律免责**: 本工具仅供参考，不构成法律意见
5. **隐私保护**: 处理敏感图片时注意隐私保护
