# OpenClaw 技能集合

[English README](README.md)

## 简介

本仓库为openclaw提供全方位的技能适配方案。整合了7个高频实用场景下的13个技能，覆盖自动开发、运营推广、办公效率、数据处理、合规审核等多维度需求。所有技能均可直接部署于openclaw，实现快速调用与高效运维。

本技能集合聚焦openclaw的场景化落地，无需复杂配置，开箱即用，助力用户快速挖掘实例价值，降低多场景操作成本。可适配个人开发者、企业办公、运营人员等不同用户群体的核心需求。

### 核心能力

-   💻 **自动开发助手**：专注后端开发、代码生成、测试编写与GitHub自动化。
-   📱 **小红书运营助手**：热点挖掘、竞品研究、内容创作、配图生成与发布排期。
-   📊 **每日热点追踪系统**：监控微博、知乎等平台的科技数码热点，自动生成内容草稿并进行QQ提醒。
-   📝 **教师办公助手**：辅助学生成绩管理、数据分析、报告生成与家校沟通。
-   🔍 **日志分析**：进行日常错误日志分析、问题诊断、提供解决方案与知识归档。

## 技能列表

| 技能 | 说明 |
| :--- | :--- |
| `github-auth` | GitHub 认证配置。设置 SSH 密钥或个人访问令牌以进行远程操作。当用户需要配置 GitHub 访问权限时激活。 |
| `github-remote` | GitHub 远程操作。支持克隆、推送、创建分支、创建 PR、Issue 和 Release。当用户需要与 GitHub 仓库交互时激活。 |
| `huawei-image-gen` | 使用华为云 MaaS 平台的 Qwen-image 模型生成图片。 |
| `xhs-image-advisor` | 小红书配图方案生成。基于文章内容和账号调性制定配图策略，生成8维度 prompt，并调用 `huawei-image-gen` 生成图片。 |
| `xhs-researcher` | 竞品研究工具。使用搜狗微信搜索进行内容角度研究，结合全网搜索分析竞品，提炼差异化角度，为选题提供数据支撑。 |
| `xhs-scheduler` | 小红书智能排期发布器。帮助内容创作者实现自动化内容排期和定时发布。 |
| `xhs-trending` | 多平台热点抓取。过滤与小红书账号领域相关的热点，输出 TOP 热点列表。 |
| `xhs-writer` | 小红书内容创作套件。离线生成爆款标题、正文、话题、评论和多卡图片 Markdown，全方位支持多类型主题。 |
| `teacher-assistant` | 教师办公助手。提供完整的家校沟通和学生成绩管理系统。当用户提及学生成绩、家长沟通、成绩分析、发送成绩报告、上传成绩文件或需要生成学生报告时激活。 |
| `og-analyzer-pro` | 专注于日志分析、系统监控、故障诊断和自动化运维。 |
